  • Dominio:

    Un nombre de dominio es la dirección de un sitio web en Internet

  • Sub Dominio:

    Un subdominio es una manera de crear una dirección web única que sea parte de un dominio más grande.

  • URL:

    Es la ubicación de una página web o de un archivo en Internet.

  • DNS:

    El sistema DNS de Internet funciona como una agenda telefónica donde se administra el mapeo entre los nombres y los números.

  • Hosting:

    Un hosting es un servicio de alojamiento web que te permite publicar un sitio web o aplicación en Internet.

  • FTP:

    FTP (Protocolo de transferencia de archivos) es un protocolo de red estándar utilizado para la transferencia de archivos de un host a otro a través de una red basada en TCP, como Internet.

  • HTTP:

    UEl protocolo de transferencia de hipertexto (HTTP) es un protocolo o conjunto de reglas de comunicación para la comunicación cliente-servidor.

  • HTTPS:

    El servidor web y su navegador intercambian datos como texto sin formato. En resumen, el protocolo HTTP es la tecnología subyacente que impulsa la comunicación de red. Como su nombre indica, el protocolo seguro de transferencia de hipertexto (HTTPS) es una versión más segura o una extensión de HTTP.

  • W3C:

    El World Wide Web Consortium (o W3C) es el organismo mundial encargado de desarrollar las tecnologías y protocolos que han hecho posible la Web que hoy conocemos,

  • UTF-8:

    UTF-8 es un formato de codificación de caracteres Unicode que ha revolucionado el mundo digital.
